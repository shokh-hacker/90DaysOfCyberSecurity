## 🔐 Cybersecurity learning overview

This repository is a structured cybersecurity learning path, and the most useful resources can be grouped into three areas:

- Learning roadmap and study plan
- Practical labs and CTF platforms
- High-quality GitHub repositories for tools and knowledge

### Recommended GitHub repositories for cybersecurity

These repositories are especially useful for self-learners and aspiring security engineers:

- [90DaysOfCyberSecurity](https://github.com/farhanashrafdev/90DaysOfCyberSecurity) — a 90-day study plan covering networking, Linux, Python, traffic analysis, cloud, and ethical hacking.
- [h4cker](https://github.com/The-Art-of-Hacking/h4cker) — one of the best collections of ethical hacking, bug bounty, DFIR, reverse engineering, and AI security resources.
- [strix](https://github.com/usestrix/strix) — AI-powered penetration testing tool to detect and fix application vulnerabilities.
- [x64dbg](https://github.com/x64dbg/x64dbg) — Windows user-mode debugger frequently used for reverse engineering and malware analysis.
- [shannon](https://github.com/KeygraphHQ/shannon) — AI pentesting tool for web apps and APIs that identifies attack vectors and validates vulnerabilities.
- [sniffnet](https://github.com/GyulyVGC/sniffnet) — network traffic monitoring and packet analysis tool.
- [SafeLine](https://github.com/chaitin/SafeLine) — self-hosted WAF and reverse proxy for protecting web apps.
- [wazuh](https://github.com/wazuh/wazuh) — open-source XDR/SIEM platform for monitoring security events.
- [crowdsec](https://github.com/crowdsecurity/crowdsec) — IDS/IPS, WAF, and malicious IP blocklist ecosystem.
- [vuls](https://github.com/future-architect/vuls) — vulnerability scanner for Linux, containers, OS packages, and network devices.
- [MISP](https://github.com/MISP/MISP) — threat intelligence platform for collecting and sharing cyber threat data.
- [suricata](https://github.com/OISF/suricata) — network intrusion detection and prevention engine.
- [awesome-ml-for-cybersecurity](https://github.com/jivoi/awesome-ml-for-cybersecurity) — curated list of machine learning resources for security.
- [awesome-incident-response](https://github.com/meirwah/awesome-incident-response) — curated incident response and forensics tools.
- [Security-101](https://github.com/microsoft/Security-101) — beginner-friendly security learning materials by Microsoft.

### What these repositories are for

- Learning and roadmap repositories help you structure your study path.
- Tool repositories help you practice real-world security tasks.
- Curated lists help you discover materials across different domains like web security, network security, malware analysis, and cloud security.

### Best learning resources by domain

- Networking: Professor Messer, Wireshark, Cisco NetAcad
- Security fundamentals: Security+, MITRE ATT&CK, NIST basics
- Linux: Linux Journey, LabEx, Linux Unhatched
- Python for security: Real Python, Codecademy, HackerRank
- Traffic analysis: Wireshark, tcpdump, Suricata
- Cloud security: AWS, Azure, GCP learning paths
- Ethical hacking: Hack The Box, TryHackMe, Vulnhub
- Career prep: resume templates, LinkedIn, Indeed, CyberSeek

### Suggested study order

1. Start with networking and security fundamentals
2. Learn Linux and Python
3. Study traffic analysis and SIEM tools
4. Move to cloud security and ethical hacking
5. Practice with labs, CTFs, and home lab environments
6. Build a portfolio and prepare for job applications

### Practice platforms

- [TryHackMe](https://tryhackme.com)
- [Hack The Box](https://hackthebox.com)
- [Vulnhub](https://vulnhub.com)
- [Cyber Talents](https://cybertalents.com)

This combination of structured learning path, hands-on labs, and practical GitHub projects is a strong foundation for entering the cybersecurity field.
